# The Life of a File

FirmWorks Files provides a myriad of components to assist in working with Salesforce files. The story begins with ingestion of the file via uploading to Salesforce.

### Uploading

#### Upload up to thousands of files at once with Enhanced Upload

Native Salesforce limits users to 10 at a time (Limit can be increased to 25)

Firmworks Files gives users the ability to upload thousands at a time.
![bulk upload](images/life-of-a-file/bulkupload.gif)

#### Upload new versions and skip duplicates
![bulk upload duplicate detection](images/life-of-a-file/bulk-duplicate-detection.png)

#### Tag files with their correct taxonomies during upload
![taxonomy support](images/life-of-a-file/taxonomy-support.gif)

#### Curate experiences to minimize users uploading the wrong documents
![curate buttons](images/life-of-a-file/curate-buttons.png)

### Tagging

#### Tag files easily and quickly that are already in the system

![gridview](images/life-of-a-file/gridview.gif)

#### Tag, relink or re-own hundreds of files in one step with bulk actions

Select the files from any search and set their tags, find and replace in text fields, link them to records or change their owner together. See [Bulk Actions](bulk-actions.md).

#### Find the files that slipped through untagged

The [Files Dashboard](files-dashboard.md) counts files with no tags and opens them in File Manager, ready for bulk tagging.

#### Create processes and workflows to audit files for accuracy

Support files in flows and automation

### Maintaining

#### See every version of a file and prune the ones you no longer need

The Versions tab lists each version with who uploaded it, opens older versions in the viewer, and can collapse the history to the latest version to free storage. See [Versions](component-appendix.md#versions).

#### Watch storage, licenses and setup from one page

The [Files Dashboard](files-dashboard.md) shows file storage, license seats, configurations, reports, schedules and automations with links to manage each.
